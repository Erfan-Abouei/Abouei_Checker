# Maintainers

## Current maintainer

- **Erfan Abouei** — project owner, roadmap, architecture, releases.
  Contact via GitHub: <https://github.com/Erfan-Abouei>

No private email is published here; use GitHub issues for general contact
and GitHub's private vulnerability reporting for security matters
(see `SECURITY.md`).

## Responsibilities

- Keep the roadmap, CLI contract, and documentation accurate.
- Review pull requests for correctness, scope, tests, and documentation.
- Run quality gates (`make verify`, race, coverage, lint, vulnerability
  scans) before merging or releasing.
- Publish releases only after the release checklist has evidence.
- Triage security reports privately and disclose responsibly.

## Succession

If the maintainer becomes unavailable for an extended period, governance
reverts to the repository owner's discretion. There is currently no
co-maintainer; nominations are welcome via a public issue but confer no
authority until this file is updated.
