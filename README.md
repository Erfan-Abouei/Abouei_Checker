# AboueiChecker

AboueiChecker (`abouei-checker`) is an open-source Go CLI for monitoring backend
HTTP health endpoints, detecting outages and recoveries, keeping local SQLite
history, and sending configurable webhook notifications.

> **Release status:** `main` intentionally contains no production release yet.
> The Phase 1 shared foundation is complete on the
> [`develop`](https://github.com/Erfan-Abouei/Abouei_Checker/tree/develop)
> branch, where implementation and verification continue.
